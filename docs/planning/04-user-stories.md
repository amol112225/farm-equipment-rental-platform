# User Stories

## Farmer

- As a farmer, I want to create an account so that I can access the platform.
- As a farmer, I want to search for equipment so that I can find what I need.
- As a farmer, I want to filter equipment by category and location.
- As a farmer, I want to view equipment details before booking.
- As a farmer, I want to book equipment instantly when available.
- As a farmer, I want to send a booking request when owner approval is required.
- As a farmer, I want to view my booking history.
- As a farmer, I want to cancel a booking if allowed.
- As a farmer, I want to rate and review equipment after use.

---

## Equipment Owner

- As an equipment owner, I want to list my equipment for rent.
- As an equipment owner, I want to edit or remove my equipment listings.
- As an equipment owner, I want to set rental price and availability.
- As an equipment owner, I want to choose between Instant Booking and Request Booking.
- As an equipment owner, I want to accept or reject booking requests.
- As an equipment owner, I want to view all my bookings.
- As an equipment owner, I want to track my rental activity.

---

## Administrator (Future Scope)

- As an administrator, I want to manage users.
- As an administrator, I want to manage equipment listings.
- As an administrator, I want to handle reports and complaints.
- As an administrator, I want to monitor platform activities.
