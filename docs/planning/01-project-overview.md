# Project Overview

## Project Name

**Farm Equipment Rental Platform**

## Description

The Farm Equipment Rental Platform is a web application that connects farmers who need agricultural machinery with equipment owners willing to rent their equipment.

Users can search, book, and manage equipment rentals through a simple and user-friendly interface. A registered user can also list their own equipment for rent, allowing them to act as both a farmer and an equipment owner.

The platform is designed as a web application first, with the backend architecture prepared for future Android app integration.

## Objectives

- Provide an easy way to rent agricultural equipment.
- Help equipment owners earn additional income.
- Reduce manual booking through phone calls.
- Simplify equipment discovery and booking.
- Build a scalable platform for future expansion.

## Key Features

- User Authentication
- Equipment Listing
- Equipment Search & Filters
- Instant Booking
- Request Booking
- Farmer Dashboard
- Owner Dashboard
- Booking History
- Reviews & Ratings
