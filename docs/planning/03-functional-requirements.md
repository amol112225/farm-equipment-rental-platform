# Functional Requirements

## Authentication

- User can register using email and password.
- User can log in securely.
- User can log out.
- User can update their profile.

---

## Equipment Management

- Users can list their equipment for rent.
- Owners can edit or delete their equipment.
- Owners can upload equipment images.
- Owners can set rental price and availability.

---

## Equipment Search

- Users can search equipment by name.
- Users can filter equipment by category and location.
- Users can view equipment details before booking.

---

## Booking System

### Instant Booking

- Users can book equipment immediately if instant booking is enabled.

### Request Booking

- Users can send booking requests.
- Owners can accept or reject requests.
- Users can track booking status.

---

## Dashboards

### Farmer Dashboard

- View current bookings.
- View booking history.
- Manage profile.

### Owner Dashboard

- Manage listed equipment.
- View booking requests.
- View booking history.

---

## Reviews & Ratings

- Users can rate equipment.
- Users can write reviews after completing a booking.

---

## Notifications

- Notify users when a booking is confirmed.
- Notify owners when a new booking request is received.
- Notify users when a booking is accepted or rejected.
