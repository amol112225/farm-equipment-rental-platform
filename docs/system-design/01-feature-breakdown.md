# Feature Breakdown

The Farm Equipment Rental Platform is divided into independent modules to simplify development, testing, and future maintenance.

## Core Modules

### 1. Authentication
- User Registration
- Login
- Logout
- JWT Authentication

### 2. User
- View Profile
- Edit Profile
- Manage Address

### 3. Equipment
- Add Equipment
- Edit Equipment
- Delete Equipment
- Upload Images
- Set Rental Price
- Manage Availability
- Select Booking Type

### 4. Search
- Search Equipment
- Category Filter
- Location Filter
- Price Filter
- Equipment Suggestions

### 5. Booking
- Instant Booking
- Request Booking
- Booking History
- Booking Status
- Cancel Booking

### 6. Dashboard
#### Farmer Dashboard
- Current Bookings
- Booking History

#### Owner Dashboard
- My Equipment
- Booking Requests
- Rental History

### 7. Reviews
- Ratings
- Reviews

### 8. Notifications
- Booking Updates
- Booking Reminders

### 9. Admin (Future)
- User Management
- Equipment Management
- Reports
